## Product brief / press background

**Somebody clipped it. It's probably in here.**

You remember the creator. Maybe the game. Definitely the bit where everything went wrong.

clpr sorts Twitch clips by creator, topic, and tag so you have somewhere to start looking. Find a clip, save it into a playlist, and send the collection to the people who missed the stream.

Viewers can also submit existing Twitch clips, vote, and comment. clpr is a responsive web application built by Subcult.

Explore clpr: https://clpr.tv/

## FAQ

**What is clpr?** A web application for discovering Twitch clips and collecting them into playlists.

**How can I find a clip?** Search or browse by creator, topic, tag, or Twitch category. Start with the detail you remember.

**Can I share a collection?** clpr supports saving clips into playlists and sharing them. Check the playlist's visibility before sending the link.

**Does it create clips from a stream?** Stream clip extraction is outside the current release. Submission is for an existing Twitch clip.

**Is there a native mobile app?** clpr is available on the web. Native mobile apps are planned.

**Where can I report a problem?** Use the [issue tracker](https://git.subcult.tv/subculture-collective/clpr/issues). Check its sign-in requirements before using it as a campaign's feedback destination.
